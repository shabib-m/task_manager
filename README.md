# Task Manager لوحدة Backdrop CMS

وحدة لإعداد أنواع المحتوى كمهام وإدارة حقولها من لوحة Backdrop. يمكنها إنشاء نوع محتوى `Task` أو ربط نوع موجود، ثم إضافة الحقول الناقصة وإنشاء View لإدارة المهام. كما تدعم التعليقات على المهام، مع إمكانية إرفاق صور وملفات بالتعليقات وتحديث حالة المهمة من التعليق.

## المتطلبات

- Backdrop CMS من سلسلة `1.x`.
- وحدات Backdrop: Field وImage وDate وFile وComment وOptions.
- وحدة Views مفعّلة لعرض صفحة إدارة المهام.

## التثبيت

1. نزّل المستودع أو انسخه إلى مجلد وحدات Backdrop، مع إبقاء المجلد باسم `task_manager`، مثل:

   ```text
   modules/task_manager
   ```

   يجب أن يكون الملف `task_manager.info` مباشرة داخل مجلد `modules/task_manager`.

2. من **Functionality → Install new module** أو صفحة **Extend** في لوحة الإدارة، فعّل الوحدات المطلوبة ثم **Task Manager**. تأكد من تفعيل Views إذا أردت صفحة قائمة المهام.

3. امنح دورًا إداريًا موثوقًا صلاحية **Administer task manager**. هذه الصلاحية تتيح إنشاء أنواع المحتوى والحقول وتفعيل التعليقات.

4. افتح صفحة الإعدادات:

   ```text
   admin/config/content/task-manager
   ```

   اختر إنشاء نوع `Task` جديد أو ربط نوع محتوى موجود، ثم احفظ. عند ربط نوع موجود، أعد تحديد الأنواع المرتبطة التي تريد الإبقاء عليها قبل الحفظ.

5. امنح الأدوار المناسبة الصلاحيات التي تحتاجها:
   - **Access task management** لعرض `admin/content/tasks`.
   - **Change task status** للسماح بتغيير حالة المهمة من التعليقات.

## الحقول والملفات

تضيف الوحدة، عند عدم وجودها، حقول وصف المهمة وحالتها وتاريخها وصورها وملفاتها. كما تهيئ التعليقات وتضيف حقول حالة التعليق والصور والملفات.

تفضّل الوحدة مخطط التخزين الخاص `private://` إذا كان مضبوطًا. عند عدم توفره، تستخدم `public://` وتعرض تحذيرًا؛ الملفات العامة قد تكون قابلة للوصول مباشرةً لمن يعرف رابطها، ولا تحميها صلاحيات عرض المهمة أو التعليق. يقرر صاحب الموقع ما إذا كان هذا مناسبًا لمحتواه. لإيقاف التخزين العام، اضبط مسار الملفات الخاصة في `settings.php` ثم أعد حفظ إعدادات الوحدة. تغيير الإعداد لاحقًا لا ينقل الملفات أو يغيّر مخطط الحقول التي أُنشئت مسبقًا.

## إزالة الوحدة

إلغاء تثبيت **Task Manager** يحذف إعدادات الوحدة وView إدارة المهام، لكنه لا يحذف أنواع المحتوى أو الحقول أو البيانات تلقائيًا.
